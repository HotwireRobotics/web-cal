How do I get a token?
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Resource owner: the repository owner. Repository access: Only select repositories → this repository.
  3. Repository permissions → Contents → Read and write. Pick an expiration date (the end of the season works).
  4. Generate the token, copy it, and paste it above. If the organization requires approval, an owner has to approve it first.

The token stays in this browser only. Anyone who has it can edit this repository, so don't share it or save it on shared computers.
